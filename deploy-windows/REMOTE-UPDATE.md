# 從自己的電腦遠端更新公司主機

公司主機固定為 `192.168.0.2`，程式目錄為 `D:\SYS\AR-SYSTEM`。遠端更新只允許公司內網連線，不開放網際網路，也不會把 Windows 密碼存進程式。

## 第一次：公司主機只需設定一次

1. 在公司主機執行一次原本的「更新 AR 系統」，取得這些新檔案。
2. 在 `D:\SYS\AR-SYSTEM\deploy-windows` 按兩下 `setup-remote-update.bat`。
3. Windows 詢問是否允許系統管理員權限時，按「是」。
4. 看到 `Remote update is ready.` 即完成。畫面也會顯示以後遠端連線要使用的 Windows 帳號。
5. 公司主機必須保持開機並登入這個 Windows 帳號；Docker Desktop 與資料庫仍照原本方式運作。

這一步只需要做一次，之後不必再到公司主機按更新。

## 以後：在自己的電腦按一次

1. 自己的電腦先取得新版程式，按兩下 `deploy-windows\remote-update.bat`。
2. 第一次會在桌面建立「遠端更新公司 AR 主機」捷徑，以後直接按這個捷徑。
3. 輸入公司主機的 Windows 帳號與密碼。密碼由 Windows 遠端連線使用，本程式不會保存。
4. 等畫面顯示 `Success`，再開啟 `http://192.168.0.2:3001` 並按 **Ctrl + F5**。

遠端更新會在主機執行原本的完整更新流程：保留主機連線設定、抓取新版程式、安裝套件、更新本機資料庫欄位、重新啟動 3001 網頁，最後檢查網頁是否恢復回應。主機更新時，網頁會短暫無法使用。

## 無法連線時

- 自己的電腦必須連接公司內網；人在外面時，需先連公司 VPN，不能直接透過網際網路連進主機。
- 確認公司主機已開機、已登入 Windows，而且已完成上面的第一次設定。
- 若 Windows 找不到 `ssh`，請在「選用功能」安裝 **OpenSSH 用戶端**。
- 主機更新紀錄位於 `D:\SYS\AR-SYSTEM\deploy-windows\remote-update.log`，截圖時請附上更新視窗最後的訊息。
